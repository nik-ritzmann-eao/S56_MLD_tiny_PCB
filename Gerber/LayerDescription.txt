Layer Description
=================

S56_MLD_tiny.GTP: Top Paste Mask
S56_MLD_tiny.GTS: Top Solder Mask
S56_MLD_tiny.GTL: Top Layer
S56_MLD_tiny.G1:  Mid1 Layer
S56_MLD_tiny.G2:  Mid2 Layer
S56_MLD_tiny.GBL: Bottom Layer
S56_MLD_tiny.GBS: Bottom Solder Mask
S56_MLD_tiny.GBP: Bottom Paste Mask
S56_MLD_tiny.GKO: Board Outline

S56_MLD_tiny.BTO: Top Overlay Layer (not provided)
S56_MLD_tiny.GBO: Bottom Overlay Layer (not provided)

S56_MLD_tiny.GG1, s56_mld_tiny-roundholes-plated.txt: Plated through-hole Top <--> Bottom
S56_MLD_tiny.GG2, s56_mld_tiny-roundholes-plated.tx1: Plated through-hole Top <--> Mid1 (blind vias)
S56_MLD_tiny.GG3, s56_mld_tiny-roundholes-plated.tx2: Plated through-hole Mid2 <--> Bottom (blind vias)
s56_mld_tiny-roundholes-nonplated.txt:                Non-plated through-hole Top <--> Bottom
s56_mld_tiny-slotholes-nonplated.txt:                 Non-plated slots Top <--> Bottom
